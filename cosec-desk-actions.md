# Cosec Desk actions

Import the [cosec-desk-actions folder](cosec-desk-actions/) into G-Work. It contains SKILL.md, the HTTP client and the complete action procedure.

Use the employee’s existing restricted Neon connection. G-Work can use dashboard task, record, assignment, review, handover, billing and staff-management operations according to that employee’s current dashboard permissions.

The live menu at https://cosec-desk.vercel.app/api/gwork supplies current argument schemas. Refresh existing morning-brief, CTC or SSM imports to get the same bundled support.
