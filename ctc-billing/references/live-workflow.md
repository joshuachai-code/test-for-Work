# Save and submit completed CTC work

Use the matching company identity and the verified work product. Company information is in the configured Boardroom OneDrive root under Company Information. Reuse the job and run identifiers when retrying. Once the worker confirms the exact completed work and submission, prepare a private JSON input with task_id, job_id, run_id, company_name, company_id, created_date, completed_date, pages (certified pages per copy), copies, and file (path to the completed PDF). Supply due_date and printed (actual total printed pages) when known. Dates use YYYY-MM-DD and counts are integers. Preserve unknown printing as null. Use zero only for confirmed no printing.

Run `python3 scripts/records.py record-work "/path/to/job.json"`. The helper delivers the reviewed bytes under Completed Forms/<task_id>, saves and reopens both matching job/run rows under CTC Records, records GWork as the preparer, and returns a price-free completion note. Use the successful helper receipt as the file and workbook read-back. If it reports a failure, reconcile the affected file or row. Append the run ID to that note and retain the exact returned CTC counts line, path and hash. The Director’s billing page reads that counts line from the task. A local OneDrive read-back establishes local persistence. Confirm cloud availability separately when evidence is available. A conflicting file or record requires reconciliation, never silent replacement. A corrected deliverable uses a versioned filename and corrected run.

Use [dashboard completion](dashboard-completion.md) for role checks, the restricted completion operation, idempotency and read-back. Use the stable SHA-256 of a private per-run manifest containing the delivery receipt and book read-backs as output_sha256. For a completed linked document or milestone use the catalog’s submit_task operation and the same price-free note. The confirmation already given for the exact task authorizes its submission after successful saves. If a save or submission fails, report the stage and retry the outstanding step with the same IDs. Never manufacture a file or approval for an unfinished physical action.

The reviewer retrieves the deliverable from the task’s Completed Forms folder and compares it with the assignment. If available append a separate `Review link: <private OneDrive URL>` line for the review button in Cosec Desk. On a different device the folder must be shared and synced or the shared link must open for that reviewer. A local path alone does not grant access. Approval and return are explicit Team Leader decisions.
